## 📋 Visão Geral

Este projeto é destinado ao estudo avançado e consolidação prática em **Node.js** e desenvolvimento de **APIs RESTful**. O conteúdo abrange desde conceitos fundamentais do runtime até a implementação de servidores HTTP, middlewares, persistência de dados e autenticação de aplicações.


## 🚀 Módulos de Estudo & Estrutura

```
codificacao-back-end/
├── 📑 modulo-01-fundamentos/
│   ├── arquiteto-node-v8/
│   ├── event-loop-microtasks/
│   └── npm-package-json/

```

### Progresso das Aulas

- [x] **Aula 01: Fundamentos do Node.js & NPM**
  - V8 Engine, Call Stack, Event Loop, Microtasks e Macrotasks.
  - Gestão de dependências e scripts via `package.json`.


## 🛠️ Tecnologias & Ferramentas

| Categoria | Tecnologia | Uso e Finalidade |
| :--- | :--- | :--- |
| **Runtime** | `Node.js (v18+)` | Execução do ecossistema JavaScript no servidor |
| **Framework Web** | `Express.js` | Criação de servidores HTTP, rotas e middlewares |
| **Linguagem** | `JavaScript (ES6+)` | Desenvolvimento da lógica e regras de negócio |
| **Gerenciador** | `NPM` | Gerenciamento de pacotes e scripts do projeto |
| **Versionamento** | `Git & GitHub` | Controle de código-fonte e histórico de revisões |

## 💻 Como Executar o Projeto

### Pré-requisitos
Certifique-se de possuir em seu ambiente:
* **Node.js** (v18.0.0 ou superior)
* **NPM** instalado
* **Git** configurado
